# 长期几何范围的动态房间分割

该层直接处理 `StructuralMapBuilder.coverage & ~walls`，不读取短期导航占据图，不读取 CLIP 类别作分割依据，也不需要先有在线 Room/Portal。它划分的是当前已观测的候选空间，而非完整建筑平面真值。没有覆盖的范围保持未知；高柜误墙、视野缺口和不完整轮廓可能形成额外候选，随着扫描可以重新划分。

## 几何方法

`partition.py:GeometricRoomPartition` 计算覆盖区域到外边界/已知墙的距离场。以局部宽阔处的距离峰值作为种子，按净空递减优先扩展，再依据相邻区域的连接净空合并：连接宽度超过 `opening_max_width_m`，或连接净空与较宽区域峰值之比没有明显收缩，则归为同一区域。对一格的栅格量化误差给予容差，防止细线因宽度在一格和两格之间波动反复分段。

四邻域为主；一格宽斜线在无正交连接时允许对角连接，避免一条连续斜线变成一串孤立房间。两个宽阔空间中间很短的窄连接归入一侧，作为开口而非第三个房间。默认先进行下述小尺度填补和平滑，再分割。细长条保留覆盖，但默认合并到邻接区域，不单独制造开口；同时关闭 cleanup_enabled 和 suppress_thin_regions 可恢复原始分割方式。不会做凸包补全。

相邻区域的分界构成几何 Portal 候选，同一房间对的多处不连续连接分别记录。候选包含 Pn、两侧 Rn、中心、宽度、法向及端点。它们不是 RGB-D 门检测已验证的门，也不会自动下发探索或运动指令。页面仅显示 Pn，候选性质在悬停和详情中说明；原 YOLOE/深度门检测及穿越确认逻辑没有替换。

## 编号与中心

几何变化后重新分割，用新旧格子重叠量按从大到小的一对一匹配继承编号。分裂时一块继承旧 ID，其他块获得新 ID；合并时主要重叠块继承 ID，旧 ID 列入 retired_room_ids；每块保留 parent_room_ids。编号不重复利用。它是简易空间重关联，不承诺每次轮廓剧变都维持人工理解的同一房间。

中心为区域所有格子中心的面积平均，即几何质心。凹形区域的质心可能位于区域之外；不偷偷改成入口或机器人轨迹点。页面在该位置标示 Rn 和当前类型。区域身份独立于旧在线图的 Rn 命名空间，API 的 `source=geometry_partition` 标明来源，旧 rooms/portals 保持原意。

## 语义汇总

每个几何区域只汇总自身有语义证据格子的**全部类别分布**。设格子历史融合分布为 p，证据权重为 w，区域分布为 `sum(w*p)/sum(w)`，取最大项作为 room_type；不对格子 Top1 进行多数投票。unknown 格子不参与，也不会用整个节点标签回填原始语义图。语义变化可以改变房间类型，不会改变边界或 ID。没有语义证据显示“等待识别”。CLIP/DINO 当前选择的证据图均适用，记录中的分数不是校准准确率。

几何分割随长期地图 revision 更新；语义汇总随语义 revision 更新。没有变化时复用结果，普通位姿变化不重复求距离场或汇总所有格子。工作在现有观察者执行器中，出错仅显示房间分割错误，不改变导航状态。

## 配置和输出

Isaac 使用 `isaac_demo/config/room_memory.json`；Habitat 使用 `habitat_demo/room_memory/config/default.json`。继续传 `--room-memory --room-semantic-backend clip` 即可，无需新 CLI 开关。

```json
"partition": {
  "enabled": true,
  "peak_neighborhood_m": 0.4,
  "opening_max_width_m": 1.6,
  "opening_ratio": 0.75
}
```

- `enabled=false`：回到原先在线 Room/Portal 的范围显示，保留语义投影功能。
- `peak_neighborhood_m`：距离场种子检测邻域，不是删除小区域的面积阈值。
- `opening_max_width_m`：作为窄口候选的连接宽度上限，单位米。
- `opening_ratio`：相对净空收缩判断；越大越容易保留几何分界。

`/api/room-memory.room_partition` 返回房间、边界、质心、语义汇总、Portal 候选、当前区域、编号继承及耗时。session 下保存 `room_partition.json` 与 `room_partition.npz`（owner 编号栅格、原点、分辨率），graph.json 也保留最新分割快照。owners=-1 表示未分配的未知或墙，不表示房间。

默认当前环境已有 SciPy；项目声明 `scipy>=1.8` 供新环境安装。未修改既有 Conda 环境。重启自己的仿真终端 B 并强刷网页后启用，导航模型终端 A 无需重启。

## 验证

合成测试覆盖：无 Portal/无语义的窄口分割、细长分支、单格候选、斜线连接、洞和墙保留、增长/拆分/合并编号继承、语义变化不改变几何、双开口分离、session 重置及网页质心标签。已有 Isaac session 的结构栅格做了离线重放；未启动 Isaac 导航，分割不是人工标注房间准确率评测。


## 小空洞、孤点与毛刺清理（2026-10-19）

在长期范围图的派生副本上处理，原始 coverage/walls 和短期导航地图不改写；所有步骤每次从原始证据重新计算，不累积腐蚀。新真实观测仍能改变下一次结果。

默认参数位于 partition：

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| cleanup_enabled | true | 清理开关 |
| smooth_radius_m | 0.10 | 形态学圆盘核半径，按网格分辨率向上取整 |
| fill_max_area_m2 | 0.09 | 外边缘小缺口的面积上限 |
| fill_max_extent_m | 0.35 | 外边缘小缺口的最大轴向跨度 |
| speck_max_area_m2 | 0.04 | 可移除孤点/毛刺的面积上限 |
| speck_max_extent_m | 0.25 | 可移除部分的最大轴向跨度 |

先用形态学开运算识别突出部分，但仅删除同时满足面积和跨度条件的部分；删除后若造成局部连通块增加则保留，以保护狭窄连接。长薄分支因为跨度较大不会被整条删除。随后按独立的内部洞参数填补同时满足面积和跨度的封闭洞；含较长或边界连通墙体的洞整体拒绝；完全封闭的小墙格孤岛按下述独立规则处理。最后用闭运算修补小边缘缺口，不修补大洞的局部角落，不恢复刚删除的毛刺，不连接不同的局部覆盖分量，也不填墙。

清理是几何假设，不是新增测量；新填格子不会被伪造 CLIP 分数。API 的 room_partition.cleanup 给出 filled_cells/removed_cells。默认细长分支合并到邻接区域，孤立细条没有邻接区域时不产生开口；仍不能保证所有假开口消失。

当前开口判定：对清理后的范围求到边界/墙的距离 d；相邻空间边界处最大连接净空为 s，区域内最大净空为 p。只有 `2*s <= opening_max_width_m` 且 `s + cell_size < opening_ratio * max(p_a,p_b)` 才保留该分界，而非合并成同一区域。默认上限 1.6 m、比例 0.75。分界的连续片段分别生成 P 节点。它是基于窄颈的几何候选，不要求视觉门框，也不表示机器人已经验证可通过。

地图上的 Portal 文字仅显示 Pn，候选状态保留在悬停与详情。类型后的 ? 来自 topological_status=prospective（未进入的候选区域），不是 CLIP 分数阈值；当前保留该标记。

## 细长条抑制与较大内部空缺（2026-10-19 晚）

- `internal_hole_max_area_m2=2.0`、`internal_hole_max_extent_m=4.0`：只针对完全被范围包围的空缺；含墙格的洞仅在满足下述更小的墙格孤岛阈值时填补。外部连通缺口仍使用原来的 0.09 m² / 0.35 m 限制，不做大范围外推。
- `suppress_thin_regions=true`、`thin_max_width_m=0.45`、`thin_min_aspect=3.0`：分割后的区域宽度以两倍最大边界净空估计；宽度不超过 0.45 m 且最大轴向跨度至少是宽度三倍时，归为细长条。将其合并到邻接净空最大的区域，保留其覆盖格子，不再单独形成房间分界与 P。没有邻接区域的独立细条保持覆盖，但没有 P。
- 填洞是房间范围的几何补全假设，不是证明内部无障碍；不会填充导航占据图，也不会虚构缺失的语义观测。

## 内部碎墙与过窄开口（2026-10-20）

`cddd1ef9a7cd4b8d96d99e31d93491a8` 的 P10–P15 均连接 R9/R10，宽度均为 0.10 m。原因不是旧 P 残留，而是内部碎墙让几何界面变成多个不连续接触段；先前填洞一旦含墙格就拒绝，且开口没有最小宽度。

新增 `partition` 参数：

- `opening_min_width_m=0.45`：分界每个连续接触段的估计宽度不足此值时不生成 P，也不加入 connected_room_ids。保留区域覆盖与编号；不因没有有效开口就擅自合并两块区域。该阈值是几何开口筛选，不是实际可通行保证。
- `fill_internal_wall_islands=true`：完全封闭的内部空缺若包含碎墙，允许在派生房间范围上补全。背景按八连通判定，斜向连到外部的空缺也不视为内部洞。
- `wall_island_max_area_m2=0.10`、`wall_island_max_extent_m=0.60`：整个洞须同时满足面积与最大轴向跨度限制；较长墙体、大洞、与外部连通的墙体保持。关闭此功能可恢复严格保留所有墙格的策略。

原始 coverage、wall_hits、导航占据图、CLIP 证据不改写。此操作是房间尺度的简化假设，不是识别出家具或证明墙体不存在；后续观测形成更长墙体后，下一轮重新从原始证据计算并恢复该隔断。多视角语义仍按原算法融合，不为填补格子伪造分数。

API `cleanup.filled_wall_island_cells` 记录在房间范围层被补全的墙格数，`suppressed_narrow_portals` 记录被最小宽度规则拒绝的接触段数。该固定记录离线重放的开口从 11 个变为 3 个，R9 内部原 6 个开口消失；仍保留 8 个几何区域，R9/R10 不被强行合并。离线从头编号与原 session 不同。
